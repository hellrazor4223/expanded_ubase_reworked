README for Version 1.2:

This is a work in progress, based upon luke83's Expanded Ubase Mod. 
There were several bugs in the original mod. Also the MCD file UBASE_2.MCD
was somehow corrupted and the original clone lab could not be identified as such.
Some maps had incorrect or wrongly set nodes, this was also of the bugs, but
not anymore.

So far 2 maps have been redone:
 - UBASE_21 the former clone lab has been replaced by a new one
 - UBASE_2c a former empty modules has been reworked into Food Procesing

There are 2 more maps which have to be reworked.
 - UBASE_18
 - UBASE_19
